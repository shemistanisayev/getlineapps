# Support

Thanks for using Line apps. All tools are free and maintained in this repository.

## Report a bug

[Open a bug report](https://github.com/shemistanisayev/getlineapps/issues/new?template=bug_report.yml) and include:

- The tool and its version (shown in the extension's Settings, or on `chrome://extensions`)
- Your Chrome version
- The steps that lead to the problem, and what you expected instead
- A screenshot if it helps

Please do not post passwords, API keys, customer data or private URLs in an issue. Issues are public.

## Suggest a feature

[Open a feature request](https://github.com/shemistanisayev/getlineapps/issues/new?template=feature_request.yml). Tell us what you are trying to do, not only the feature you have in mind.

## Without a GitHub account

Use the feedback form on the tool's page at [getlineapps.com](https://getlineapps.com).

## Privacy

The extensions collect no data. Details per tool: [getlineapps.com/privacy](https://getlineapps.com/privacy).
