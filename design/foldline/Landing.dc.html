FAQ

Questions

Something else? Ask me directly

Is Foldline really free?

Yes. There is no paid plan, no account and no usage limit.

How is the score calculated?

Every page starts at 100. A failed High check takes 12 points, Medium takes 6 and Low takes 2. Only checks that run in the current view count, so Desktop and Mobile get separate scores.

Does Mobile view use a real phone?

No. It makes the Chrome window narrow, so the page shows its phone layout. Sites that pick a layout by device type rather than width may still show the desktop version.

Does it replace heatmaps or A/B tests?

No. Foldline checks the page itself. It doesn't watch visitors, so it is the step before testing: fix the obvious problems, then test what is left.

Does it send any data anywhere?

No. Foldline reads the page in your browser and keeps the result in memory until you close the tab. Only your settings are saved, and only on your computer.

Why do I click the icon again on a new tab?

Foldline uses Chrome's activeTab permission. It can read a page only after you ask, so it never has access to every site you visit.
