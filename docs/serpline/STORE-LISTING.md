**Detailed description**

```
See your page the way Google and AI do.

Serpline checks the page you are on: the technical SEO basics, what only shows up after JavaScript, and which AI crawlers are allowed to read it. Click the icon (or press Alt+Shift+S) and a side panel opens next to the page with a score, the issues and the fix for each one.

SUMMARY
- One SEO score out of 100, weighted by priority
- A clear answer to "Can Google index this page?" from the status code, noindex, robots.txt, canonical and sitemap
- The on-page basics Google reads first, from the title and description to structured data, each with a clear status
- Structured data checked against Google's rich result rules: what is missing for Product, Article, FAQ, Breadcrumb and more
- hreflang codes, the self link and the return links of the other language versions
- Google preview for mobile and desktop, measured in pixels, with the exact point where Google cuts the title and description

HEADINGS
- The H1 to H6 outline with skipped levels and duplicate H1s
- Headings that exist only after JavaScript are marked
- "Highlight on page" outlines every heading and every image without alt text right on the page

LINKS
- Internal, external and nofollow links with their anchor text
- A real status check of internal links from your browser: broken links (404, 410, 500) and redirects
- Links without text, vague anchors like "click here" and nofollow on your own pages, highlighted right on the page

SPEED AND MOBILE
- Core Web Vitals of your visit (LCP, CLS and INP) with Google's thresholds, plus first paint and server response time
- Page weight by type and every image that is too heavy, bigger than shown, in an old format or lazy-loaded at the top
- Mobile checks for the viewport, sideways scrolling, tiny text and small tap targets
- The server response: HTTPS, compression and caching headers

RENDER
- The raw HTML next to the rendered page, signal by signal, to see what crawlers miss
- How much of the text needs JavaScript, and exactly what is added by scripts
- What AI crawlers see: the share of text, the heading and the schema they can read, and the first words they get

AI
- Which AI search and training crawlers the site's robots.txt allows or blocks, grouped into search bots and training bots
- The exact robots.txt line behind every block
- robots.txt, sitemap and llms.txt at a glance

AUDIT PDF
- One click turns the findings into a prioritized report with every issue and its fix, ready to send to a developer

PRIVATE BY DESIGN
- No account, no server, no analytics inside the extension
- Serpline reads only the page you ask it to check. It fetches that page's raw HTML and the site's robots.txt, llms.txt and sitemap from your browser
- Link, canonical and hreflang checks go only to that same site
- Only your settings (language, preview device, link check on open) are saved, and only on your computer
- Minimal permissions: active tab, scripting, side panel and local storage. Access to a site is asked for only when you choose it, one site at a time
- Open source: https://github.com/shemistanisayev/getlineapps

Free, with no paid plan and no usage limit. Built by Shamistan Isayev, technical SEO and analytics consultant. Need help fixing what Serpline finds? https://shamistanisayev.com
```

## Privacy practices tab

**Single purpose**

```
Serpline helps people check the search engine optimization of the web page they are on: whether Google can index it, on-page SEO basics (title, description, canonical, robots, headings, image alt text, structured data, Open Graph, links), page speed and mobile layout, how much of the page needs JavaScript to appear, and which AI crawlers the site's robots.txt allows. It shows this in a side panel and can export it as a PDF.
```

**Permission justifications**

| Permission | Justification to paste |
|---|---|
| `activeTab` | When the user clicks the Serpline icon or presses its shortcut, Serpline reads that tab once to check the page. Without that action it has no access to any tab. |
| `scripting` | Runs read-only functions in the tab the user chose: one returns the page's HTML and fetches the same page's source, robots.txt and llms.txt from that site; one reads the speed numbers the browser already keeps for the page (Core Web Vitals, request sizes) and the size of its images and text, and fetches the site's sitemap and the page's canonical and hreflang pages on that same site; one checks the status of the page's internal links on that same site; one draws a removable highlight over headings, links, images or the largest element when the user turns it on. Nothing on the page is changed and nothing is sent elsewhere. |
| `sidePanel` | Shows the results in Chrome's side panel next to the page. |
| `storage` | Saves the user's settings in chrome.storage.local on their computer: interface language, the default Google preview device and whether to check links on open. Nothing else is stored. |
| Optional host permissions (`https://*/*`, `http://*/*`) | Never granted at install. Only when the user presses "Check this page" after moving to another page of a site they checked before, Serpline asks Chrome for access to that one site, and Chrome shows its own prompt. Serpline never asks for all sites. |
| Host permissions | None requested. |

**Remote code**

```
No, I am not using remote code.
```

Serpline loads no scripts, fonts or data from the network. All code and fonts are in the package. Its only requests go to the site the user is checking (the page source, robots.txt, llms.txt and internal link status), from the user's browser.

**Data usage**

Tick nothing in "What user data do you plan to collect". Serpline collects none of: personally identifiable information, health, financial, authentication, personal communications, location, web history, user activity or website content. Page data is analyzed in memory in the browser and never leaves it.

Tick all three certifications:

- I do not sell or transfer user data to third parties, outside of the approved use cases
- I do not use or transfer user data for purposes that are unrelated to my item's single purpose
- I do not use or transfer user data to determine creditworthiness or for lending purposes

## After approval

Send the listing link (`https://chromewebstore.google.com/detail/...`) to the agent. It sets Serpline to `live` with that `storeUrl` in `apps/site/src/content/tools.json`, so every "Add to Chrome" button on getlineapps.com points to the listing.
